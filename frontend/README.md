# Notula frontend

Next.js 16 / React 19 (App Router, TypeScript) · Tailwind CSS v4 · shadcn/ui primitives · Biome · vitest · pnpm.

The recap is rendered as a **meeting-as-document**: a full-width page header above a ~640px reading column (audio player, Summary | Transcript tabs, document-tight prose) beside a 300px metadata rail (action items, the measured per-stage pipeline table, re-summarize, details). Design tokens derive from a measured study of an AI meeting-recap product: accent budget of exactly one violet (`#6f5ff8`, the AA-pivot that passes 4.5:1 against white in both directions, with `#5a4bd8` for accent text on tinted surfaces), achromatic chrome separated by hairlines, and **provenance tinting** — AI-authored containers sit on a violet wash with a single "✦ AI-generated · model" caption, never per-item badges.

## Dev loop

```bash
# backend first (repo root): mock provider, no keys needed
make run                # uvicorn on :8000

cd frontend
pnpm install
pnpm dev                # http://localhost:3000 — /api and /healthz proxy to :8000
```

If the backend runs elsewhere: `NOTULA_API_URL=http://localhost:8123 pnpm dev`. Note the proxy rewrites are read from `next.config.ts` at build time, so for production set `NOTULA_API_URL` on `pnpm build`, not just `pnpm start`.

```bash
pnpm lint               # biome check
pnpm typecheck          # tsc --noEmit
pnpm test               # vitest (offline)
pnpm build              # production build
pnpm generate:api       # regenerate src/lib/api/types.d.ts from the running backend's OpenAPI
```

`src/lib/api/types.d.ts` is generated by openapi-typescript and committed, so builds never need a running backend; regenerate it after any backend schema change.
